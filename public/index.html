Privacy Architecture
How MyCircle Protects You

1. Real End-to-End Encryption: Uses standard Web Crypto API (P-256 ECDH + AES-256-GCM). Messages are encrypted on your device before leaving and decrypted only on the recipient's device.

2. Zero Central Chat Database: Chat history is stored locally in your browser's IndexedDB. The server never stores chat history or plaintext.

3. Ephemeral Relay: When a recipient is offline, the already-encrypted ciphertext is held in transient server RAM only until they connect, then immediately purged.

4. Passkey Authentication: WebAuthn Passkeys handle account access securely without sending secrets across the network.
