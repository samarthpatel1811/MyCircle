Privacy Architecture
How MyCircle Protects You

1. Real End-to-End Encryption: Uses Web Crypto API (P-256 ECDH + AES-256-GCM). Messages are encrypted on your device and decrypted only by the intended recipient.

2. Zero Central Chat Database: Chat history is stored locally in your browser's IndexedDB. The server never stores chat history or plaintext messages.

3. Ephemeral Relay: When a recipient is offline, the already-encrypted ciphertext is held in transient server RAM only until they connect, then immediately purged.

4. Forward Secrecy: When a member is removed from a group, encryption keys immediately rotate so they cannot read future messages.
